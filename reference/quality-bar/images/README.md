# Image moods

Put reference images in the folder that matches their **mood**. I use them to learn what imagery you want for each kind of email (what to search for, what to avoid, how images are used), and to pick the photos in the template library.

| Folder | What goes in it | Usually goes with the style |
|---|---|---|
| `retro-vinyl` | Nostalgic, warm, film-toned: record shops, cassettes, posters, old signage | Retro |
| `minimal-product` | Clean product shots on plain backgrounds, lots of space | Minimalist, Simple |
| `editorial-fashion` | Styled, magazine-like photography: models, eyewear, clothing | Editorial |
| `food-drink` | Snacks, cafes, bars, ingredients, packaging | Any |
| `bold-graphic` | Big type, flat colour blocks, stark contrast, picture panels with the headline in them | Brutalist |
| `bauhaus-art` | Geometric shapes, primary colours, abstract compositions | Bauhaus |
| `home-interiors` | Furniture, rooms, everyday objects, lifestyle at home | Minimalist, Editorial |
| `handmade-craft` | Illustration, sketches, paper textures, makers, toys and puzzles | Handwritten |
| `cyberpunk-neon` | Dark scenes, neon light, futuristic | Cyberpunk |
| `seasonal-holiday` | Christmas, Halloween, Black Friday, spring, summer | Any |
| `music-events` | Gigs, crowds, venues, festivals, stages | Retro, Brutalist |
| `people-portraits` | Testimonial and team photos, people using a product | Any |
| `_unsorted` | Not sure where it belongs: I will sort it | |

If an image fits two moods, put it in the stronger one (or a copy in both). If none fits, ask me to add a folder.

## Naming

`<role>__<what-it-shows>.jpg`, for example `hero__tomato-teaser.jpg` or `product__tote-bags-grid.jpg`.

Roles: `hero`, `product`, `lifestyle`, `graphic`, `illustration`, `texture`, `pattern`, `background`, `portrait`, `logo`, `icon`.

Add `__text` at the end when the headline or words are **part of the picture** (not live text), for example `graphic__coming-soon__text.jpg`. That tells me which images carry text and which are photos only.

## Good to know

- Original size is best (1200 px wide or more). No need to resize or compress.
- Write where each one came from, and what you like about it, in `../NOTES.md` section 3.
- **Images here are git-ignored by default**, so they stay on your machine and are never committed by accident (they may be other brands' photos). Anything that must ship in the product has to be free to use (Pexels, Unsplash, your own, or AI-generated by you). To commit images you are free to use, delete `images/.gitignore`.
- Other brands' emails and their images are fine for reference. Keep it that way: reference only, never copied into the product.
